MANAGE YOUR CONTENT

Question editor

Edit your question sets, preview formatting, and save your changes. Autocomplete suggestions appear as you type supported commands and syntax.

Auto-save is active. Changes are saved locally as you edit. Use Question templates to insert a standard question, typed answer, typed blanks, sentence-style blanks, multiple-choice test set, or image question. Templates are inserted at the cursor and the question placeholder is selected for easy replacement.
How to use the editor ⌄
Text-to-speech mode
• Click MATIC answering first to enable auto-answer mode
• Then click TTS to enable voice narration
• TTS will read the question and then the answer
• Adjust speech speed and pause duration using the sliders
• Click TTS button again to stop and disable
• Use EN / FIL toggle to pick English or Filipino voice
Question templates
• Click Question templates above the editor to insert a ready-made question format at the cursor.
• Available formats: standard, typed answer, numbered typed blanks, sentence-style typed blanks, multiple-choice test set, and image-based question.
• The question placeholder is selected after insertion so you can immediately replace it by typing.
Images
• Click Upload image to choose images from your computer or phone. The reference is inserted at the current cursor position.
• Use Image library to reuse saved images. Tap or click an image in the quiz or preview to enlarge it.
• Images are stored in this browser. Export a question set to include its referenced images when moving to another device.
Typed blanks (tb)
• Start the question with (tb), then write the question, a hyphen, and semicolon-separated answer parts.
• Numbered format: (tb)1. Three states - 1. (solid) is a state; 2. (liquid) is a state;
• Sentence format: (tb)3. SOGIES - 1. firstly (Sexual Orientation) is very important;
• Shorthand format: (tb)15. SOGIES - SO. (Sexual Orientation); GI - (Gender Identity);
• Typed blanks work alongside multiple.cho(), random(Test Name), and other test settings. The blank question stays a typed question.
• All blanks must be correct for the question to earn one point. Feedback identifies each incorrect blank, and retry rounds include only the blanks missed in the previous round.
Typo handling
• Minor typos are automatically accepted!
• Yellow feedback shows the corrected answer
• Click "Continue" or press Enter to proceed
Keyboard shortcuts
• Press A, B, C, or D to instantly select and submit that option
• Press Enter to submit your typed answer
