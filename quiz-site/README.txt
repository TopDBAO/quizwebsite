HOW TO ADD A SUBJECT
1. Open the quiz, tap the gear, edit/paste your questions, then tap APPLY & RESTART.
2. Tap EXPORT JSON. It downloads a file (e.g., leadership.json).
3. Put that file in the data/ folder.
4. Add a line to data/index.json: {"name": "Leadership", "file": "leadership.json"}
5. Re-upload the updated folder to your host. Everyone sees the new subject after refreshing.

Old browser-saved quizzes: Open your old file, tap the gear, then EXPORT JSON for each set.

IMPORTANT: The quiz must be opened from a web link (not by double-clicking index.html) to load data/.
