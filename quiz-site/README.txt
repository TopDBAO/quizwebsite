HOW TO ADD A SUBJECT
1. Open the quiz, tap the gear, edit/paste your questions, tap APPLY & RESTART.
2. Tap EXPORT JSON. It downloads e.g. leadership.json.
3. Put that file in the data/ folder.
4. Add a line to data/index.json:  {"name": "Leadership", "file": "leadership.json"}
5. Re-upload the folder to your host. Everyone sees the new subject on refresh.

Old browser-saved quizzes: open your old file, tap the gear, EXPORT JSON for each set.
The quiz must be opened from a web link (not by double-clicking index.html) to load data/.
